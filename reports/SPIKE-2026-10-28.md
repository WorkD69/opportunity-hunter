## (a) RenderCV

Тестовое резюме на русском с вымышленными данными (кириллица, «ёлочки», №, ₽, ё/Ё).

| Где | Время рендера | Память | Результат |
|---|---|---|---|
| Windows, Python 3.12 | 2,5 с холодный, 0,13 с повторный | — | 1 стр. A4 |
| VPS, Python 3.14, 1 vCPU | 1,2–1,3 с | пик ≈106 МБ | 1 стр. A4 |

- В PDF встроены только Source Sans 3 (текст) и Font Awesome (иконки) — подстановки другого шрифта для кириллицы нет; все контрольные строки извлекаются как текст (проверено pypdf локально и на VPS).
- Изолированный venv на томе профиля: 238 МБ, установка 20 с; системный Python Hermes не затронут. Ни LaTeX, ни Chromium не нужны.
- Найденные особенности шаблона (закрываются настройками, обязательны для этапа 3):
  - год без месяца надо передавать **числом**: строка `'2025'` разбирается как 01.2025 и печатается «Янв 2025» — это выдуманный месяц, недопустимо для резюме;
  - `typography.alignment: left` — при выравнивании по ширине появляются переносы слов, которые ломают поиск ключевых слов ATS;
  - `locale.present: н. в.` и `entries.degree_width ≈ 2.6cm` — иначе русские подписи не помещаются в колонки.

## (c) Письма hh

- hh.ru не парсится: вакансии приходят письмами (автопоиски и подборки по резюме) и пересылаются фильтром в отдельный ящик бота.
- Разобран реальный пример — письмо «Подходящие вакансии для резюме»: только HTML; в каждой карточке название (ссылка), зарплата «от/до + валюта + период» (может отсутствовать) и компания. Описания, требований и дедлайна в письме нет.
- Прототип парсера вытащил 6/6 карточек с корректными полями.
- **Безопасность:** ссылки в письме содержат параметры `loginkey` и `email_hash`; само письмо предупреждает, что ссылки персональные. Обязательные правила для этапа 4:
  1. из ссылок сохраняется только `https://hh.ru/vacancy/<id>`, любые параметры отбрасываются;
  2. сырые письма hh не хранятся в БД, не пишутся в логи, не передаются модели и не попадают в git — только очищенные карточки;
  3. бот никогда не открывает ссылки из писем с параметрами;
  4. тест-фикстура для парсера — синтетическое письмо, не реальное.
- Не проверено: формат письма именно **автопоиска** (пока есть только подборка по резюме) — нужен второй образец.

## Почта бота

- С VPS TCP 993 к Gmail, Яндексу и Mail.ru: по IPv4 — таймаут, по IPv6 — нет маршрута (IPv6 на сервере не настроен). HTTPS к тем же провайдерам работает, исходящая политика на сервере — ACCEPT. Вероятная причина — фильтрация у хостинг-провайдера; не подтверждено, владелец отправил запрос.
- Если порт не откроют — Gmail API по HTTPS с доступом только на чтение к ящику бота.
- Пересылка настроена владельцем: hh → личный Gmail → фильтр → ящик бота; учебная почта → правила пересылки (по отправителям и по ключевым словам в теме) → ящик бота. Внешняя пересылка из учебной почты подтверждена тестовым письмом.
