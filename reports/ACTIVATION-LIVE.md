Cgroup memory включает cache и не равна working-set из docker stats. Это наблюдавшийся пик данного окна, не непрерывный максимум всех предыдущих поисков. OOM нет, остальные контейнеры и соседний сервис remained running. Значимых сбоев, требующих отката, не обнаружено; был исправлен локальный дефект command routing без перезапуска.
